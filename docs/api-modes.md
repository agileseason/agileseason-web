## Режимы API: mock и real

Фронтенд работает с API через `~/api/*`. Реализацию выбирает переменная `NUXT_PUBLIC_API_MODE`:

| Режим  | Что происходит                                              | Когда                               |
|--------|-------------------------------------------------------------|-------------------------------------|
| `mock` | данные из `mocks/`, хранятся в памяти, бэкенд не нужен      | по умолчанию в dev                  |
| `real` | GraphQL-запросы на `NUXT_PUBLIC_API_URL`                    | по умолчанию в production           |

Веб-разработчику достаточно `pnpm install && pnpm dev -p 3300`. Любой `/boards/<id>` откроется
на фикстуре `mocks/board.json`.
Перетаскивание и создание задач меняют состояние в памяти до перезагрузки страницы.

Чтобы работать с настоящим бэкендом:

    NUXT_PUBLIC_API_MODE=real NUXT_PUBLIC_API_URL=http://localhost:3000/graphql npm run dev

### Как добавить метод API
1. Описать его в интерфейсе `BoardApi` (`api/types.ts`).
2. Реализовать в `api/http.ts` и `mocks/api.ts` (TypeScript не даст забыть одну из них).
3. Добавить функцию-обёртку в соответствующий файл `api/*.ts`.
